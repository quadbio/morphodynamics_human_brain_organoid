# morphodynamics_human_brain_organoid
This repository contains the scripts and code for the "Morphodynamics of human early brain organoid development" paper (Jain, Gut et al., 2025).
The corresponding raw sequencing data is publicly available through ArrayExpress under accession number: E-MTAB-15057.  
The processed scRNAseq datasets (Seurat objects) required to run these scripts are available for download via Zenodo (10.5281/zenodo.15236859). Additional .csv and .txt files required to run the code are provided in the subdirectories along with each script.
